To resolve with HASHMAP and HASHSET

------ [ ] Subarray Sum Equals K
Dado um array e um valor k, retorne true se existe algum subarray contíguo cuja soma seja igual a k.
Input:  nums = [1, 2, 3, 4, 5], k = 9  → true  (2 + 3 + 4 = 9)
Input:  nums = [1, 2, 3], k = 10       → false

------ [ ] Distinct Substring
You receive a string of N letters (7 ≤ N ≤ 1000).
You need to find the first sequence of 7 distinct characters and return its position.
The string starts at position 0. If the sequence is not found, return -1.

## Examples
Input string:
ABCDEFGHIJ
└─────┘

Output: `0`
---
Input string:

ABCABCDEFGHIJABCDEFGHIJ
   └─────┘

Output: `3`
---
Input string:

AABBCCDDEEFF

Output: `-1`

To resolve with JSON

------ [X] Total de salários
Dado o JSON abaixo, retorne a soma de todos os salários:
  [
      {"nome": "Ana", "salario": 5000.0},
      {"nome": "Carlos", "salario": 8000.0},
      {"nome": "Beatriz", "salario": 6500.0}
  ]

------ [X] Funcionários acima da média
Dado o JSON abaixo, retorne uma lista com os nomes dos funcionários que ganham acima da média salarial:
  [
      {"nome": "Ana", "salario": 5000.0},
      {"nome": "Carlos", "salario": 8000.0},
      {"nome": "Beatriz", "salario": 6500.0},
      {"nome": "Diego", "salario": 4000.0}
  ]

------ [X] Exercício — Contagem por departamento

Dado o JSON abaixo, retorne quantos funcionários existem em cada departamento:

[
    {"nome": "Ana", "departamento": "TI"},
    {"nome": "Carlos", "departamento": "RH"},
    {"nome": "Beatriz", "departamento": "TI"},
    {"nome": "Diego", "departamento": "Financeiro"},
    {"nome": "Elena", "departamento": "RH"}
]

Retorno esperado:
TI: 2
RH: 2
Financeiro: 1

Dica: você vai precisar de um objeto {} para guardar a contagem por departamento, em vez de um array. É parecido com o HashMap do Java.
